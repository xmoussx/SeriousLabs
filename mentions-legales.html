Sécurité du formulaire

Pour limiter les envois automatisés, le formulaire comporte un champ invisible que seuls les robots remplissent, et le nombre d'envois par adresse IP est plafonné. L'adresse IP de l'expéditeur est conservée le temps de ce plafonnement, soit une heure, puis elle est effacée.
